# Linguistic data

This directory holds the evidence for the language layer:

- `strings.csv` — the extracted visible strings, with a header. Regenerated by
  `scripts/extract-strings.ts`; the checked-in file is a small seed.
- `back-translation.csv` — one row per translation-memory entry: source, Fulfulde,
  French meaning (oral blind pass), meaning/naturalness scores, critical-error flag.
- `back-translation.template.csv` — the 115-row template generated from the MT
  candidates; copy the filled one to `back-translation.csv`.
- `tts-mos.csv` — TTS naturalness and intelligibility scores.
- `tts-mos.template.csv` — the 115-row voice-rating template.
- `coverage.csv` — the output of `scripts/coverage.ts` (gitignored).
- `session/` — the local listening page and WAV files (gitignored).

The release gate is defined in `docs/LINGUISTIC_VALIDATION.md`. The validation is
oral: the speaker hears the local MMS audio, gives the French meaning and rates
intelligibility. See
[`docs/decisions/0013-oral-validation-by-listening.md`](../../docs/decisions/0013-oral-validation-by-listening.md).

The Fulfulde column is intentionally empty until a native speaker fills or
corrects it. The phrasebank release build fails while medium/high-risk entries
are unvalidated.
