# Assets

Source audio and images live outside the build.

- `audio/raw/` — raw speaker recordings, 48 kHz WAV, gitignored.
- `audio/processed/` — normalized 16 kHz clips, gitignored.

The consenting speaker's consent form, the recording script and the metadata CSV are kept
with the project records, not in the public repository.

Only the demo-path audio is committed, under `apps/extension/public/audio/demo/`.
