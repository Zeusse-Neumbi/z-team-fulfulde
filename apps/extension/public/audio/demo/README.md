# Demo audio

Only the demo-path clips belong here. They are bundled into the extension ZIP.

Rules:

- Opus 48 kbps (or WAV for local testing), mono, 48 kHz or 16 kHz.
- Total size of this directory ≤ 4 MB.
- File names are stable IDs, e.g. `FF_BALANCE_IS_P1.opus`.
- Recorded by the consenting native speaker; no third-party audio.
- No real names, phone numbers, account numbers or references.
- The full phrase bank is **not** committed here; it is served locally or shipped as a
  release asset.
