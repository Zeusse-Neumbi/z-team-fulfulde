# Data

Datasets, recordings and annotations are **not** committed to this repository.

| Path | Contents |
|---|---|
| `data/common-voice-fub/` | Common Voice 27.0 — Adamawa Fulfulde (`fub`), CC0-1.0 |

| `assets/audio/raw/` | Raw speaker recordings (consent required; gitignored) |

Rules:

- No real banking data, ever.
- No personal data beyond the consenting speaker's project pseudonym.
- Do not commit datasets or recordings.
- Record the licence and the exact snapshot/version used in `THIRD_PARTY_NOTICES.md`.
- The CLARIN/NOODL Adamawa TTS dataset is **not** used for generative training.
